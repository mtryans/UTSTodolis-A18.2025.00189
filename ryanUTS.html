To Do List App

Dosen: Ibnu Utomo W, M.Kom

Deskripsi Program

Aplikasi To Do List ini dibuat menggunakan HTML, Bootstrap 5, dan JavaScript murni. Memungkinkan pengguna untuk mencatat, mengelola, dan menyelesaikan kegiatan harian dengan mudah.

  • Tambah kegiatan beserta tanggal pelaksanaan
  • Edit kegiatan yang sudah ditambahkan
  • Hapus kegiatan dari daftar
  • Tandai kegiatan sebagai selesai via checkbox
  • Dibangun dengan Bootstrap 5 & vanilla JS
